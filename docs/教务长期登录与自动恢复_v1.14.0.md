# v1.14.0 教务长期登录与自动恢复

成绩页默认显示已保存成绩，列出更新时间。“刷新统计”只重新读取保存数据；“更新所带学生的学校成绩”才向学校更新。

更新或实时查询遇到登录失效时，先静默恢复，不主动发送验证码。学校确实需要认证时，进入教务连接页，用户明确获取并输入验证码；成功后返回原页面，续接本次查询或更新一次。取消验证可继续查看已保存成绩，不提交待执行操作。网络故障不会当作需要验证码，旧查询结果保留。

长期官方浏览器状态与24小时短期教务快照独立、加密保存，并按已验证学校账号隔离；仅在受保护页面验证成功后捕获，按学校实际Cookie到期时间及应用90天保留上限处理，不承诺90天免验证。不向匿名学校登录流程注入已有SSO状态。

普通断开保留长期信息；明确“清除长期登录信息”才移除，并断开该账号多设备共用的学校/教务连接。成绩、照片和授权保留。有进行中的查询或任务时先暂停，防止清除操作影响执行。

已选择信任选项的时间与可用长期状态分别记录；点击过选项不等于学校永久信任。旧信任凭据已丢失时，升级后仍可能需完成一次验证才能建立新状态。
