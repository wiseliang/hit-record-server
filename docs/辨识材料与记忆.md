# 辨识材料与 App 内记忆（1.16）

使用当前学校账号已匹配的本人所带名单、缓存照片与教师确认资料。首页进入“辨识材料与记忆”，新建项目时填写辅导员姓名。学情按学校认定填写，空白不能自动当作“无”。

- 两版 PPT 沿用附件可编辑模板，按班级每页12人；完整版填写已核实字段，考核版只保留辅导员、班级、照片和空白栏目。草稿标记待补，提交版阻止缺项/过长内容。照片独立关系并按比例填充，去除备注及自定义属性。
- 同版式已完成的完整版 PPTX（25MiB以内）先解析、预览、班级+姓名唯一匹配，教师逐页核对；冲突可手动选择所带学生。仅确认的映射写入，空字段不覆盖。考核版不能恢复未填写答案。其他版式/PDF/OCR不在此版本范围。
- 记忆卡默认姓名、班级、班委；其他个人情况须手动开启且字段已确认。专用私人学习表不进入普通题库、不排队AI。每张卡的稳定来源ID、内容版本、照片版本与历史作答分离；旧答案作答不会覆盖新版掌握度。
- App 内先回忆再展开，“不会/模糊/熟练”采用掌心刷题同源10分钟/1天/7天复习规则。可筛班级、题型、新卡/到期卡和随机顺序；离线资料AES-GCM加密保存30天，密钥由系统安全存储保存，队列幂等同步。轮次跨设备写入采用版本冲突检查；冲突时明确选择云端轮次。

## 部署

迁移 `node scripts/migrate-v12.js` 新建 material_* 表，保留原成绩与照片数据。Python3 + Pillow 为 PPT 作业依赖（`MATERIALS_PYTHON` 默认 `/usr/bin/python3`）。`MATERIALS_ROOT` 为700私有作业目录，不能放 public/。重启会将中断任务标为失败并清除临时上传。

学校后端与掌心刷题服务共同配置32字节以上 `MEMORY_BRIDGE_SECRET`，学校额外设置长期稳定的 `MEMORY_SUBJECT_SECRET`，以及回环 `MEMORY_BRIDGE_URL`。签名含受众、路径、请求体摘要、45秒有效期、一次性nonce。学校密码/验证码不传给学习服务；App只持学校端认证。

新增 `/api/materials` 路由均须原Bearer并按openid+学校账号隔离。作业预览/下载也检查所有权、当前管理范围及资料版本。不得向公网暴露作业目录或桥接密钥。生成文件含个人资料，教师另存后需自行管理。离线期间不能实时回收已下载资料。

回归：`npm test`、`npm run test:integration`、`python3 tests/material-ppt.test.py`。使用独立数据库与合成资料。真机安装与现场辨识不由合成测试替代。
