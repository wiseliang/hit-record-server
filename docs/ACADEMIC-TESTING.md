# v1.8 教务查询测试版

工作台进入“学业查询”，连接教务并按学校要求输入HIT APP本次验证码。每位老师首次使用选择所带院系、年级、专业与行政班，支持多组范围。

- 学生档案默认显示所带班级；专业单科查询默认整个专业。
- 初次可先刷新单个学生的成绩，核对后再开始批量同步；批量支持暂停、恢复与重试。
- 单科列表中的“本次不及格成绩”来自本次课程查询；“历史判定仍未通过”依据最近一次已同步历史，注意两者更新时间。
- 补考和重修记录保留。不同课程代码不凭名字相近自动消除历史欠账；老师可以确认对应关系、填写依据、选择个人或专业范围，并撤销。
- “待核实”不表示学校已认定通过；教务原始不及格门数保留展示。
- 当前未通过与已通过判断只覆盖已读取的有效成绩；免修、未发布等状态保留待核实，不当成0分。
- 学工录入接口继续兼容v1.7；教务成绩模块只读学校数据，课程关系仅保存在本工具。

验证包含原有录入回归、隔离数据库权限与恢复测试、脱敏App页面端到端测试，以及已完成的真实教务读取器抽查。首次在手机上使用的新认证链路和各专业完整覆盖需要实测确认。

不要在反馈截图中暴露验证码、密码或完整学生成绩名单。
